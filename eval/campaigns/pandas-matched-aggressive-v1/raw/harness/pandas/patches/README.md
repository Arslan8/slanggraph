# Changes applied equally to configurations

`compatibility-requirements.txt` pins the missing IPython dependency. No upstream
source/lockfile is edited. Local provider configuration and CPU affinity are
recorded in manifests. The integration is an import-time adapter in
`../integration.py`, not a source diff: it replaces the two computation helper
aliases. C delegates the original sandbox program to `../worker.py` in the existing
Linux executor. A/B retain original subprocess launch. See the application README.

Controlled implementation variants are generated by `fault_variant` only when a
case has an explicit `fault` field. Exact resulting code is saved in each run's
events. Normal baseline code has no fault injection. These variants preserve the
legitimate return and attempt one effect immediately before it.
