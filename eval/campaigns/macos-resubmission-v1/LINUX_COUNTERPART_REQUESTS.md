# Linux counterpart requests for macOS-only extensions

The pinned 45-case common matrix needs no new Linux execution. These requests apply **only if** the resubmission wants to promote a macOS-only extension into a later matched-host claim. The Linux student owns Linux execution and may use host-specific launch code, but should keep the stated guarantee, attacker action, fixture, and independent oracle. The full macOS case list is in `cross-host-common-cases.json` under `macos_only_extensions`; raw macOS outcomes are in `advanced-verification.json` and `security-verification.json`.

| macOS case IDs | Shared guarantee and attacker action | Required independent oracle |
| --- | --- | --- |
| `inherited_fd`, `inherited_env`, `startup_inventory` | Fresh worker must not inherit a deliberately inheritable private descriptor or credential. Probe direct read and inventory before user code. | Successful unprotected marker/credential control; protected descriptor and environment inventory plus absent private marker. |
| `race_rename`, `race_symlink`, `race_hardlink`, `private_alias` | Mandatory direct filesystem **object** read must retain the selected object identity or refuse before execution. Substitute at an after-ready/before-`GO` barrier. | File content and `fstat` device/inode returned by worker compared with independently read substituted target and private marker; record whether worker was released. The existing Linux filesystem regression is not automatically equivalent unless it uses this grant and barrier. |
| `child_channel` | A child must not reuse broker authority to write Bob. Fork and send a Bob write on the inherited channel. | Independent Bob SQLite backup and resource log, plus child process identity. |
| `parallel_confusion` | Parallel requests cannot exchange principal, invocation, selector, or response. Run eight Alice/Bob calls against one mediator with varied arrival order. | Per-call bound response and mediator event log, Bob SQLite backup, and observed call order. |
| `pending_cancellation` | After cancellation, no result reaches the canceled graph caller and worker/guardian terminate; an already authorized mediator read may finish. Hold the mediator at a barrier, cancel graph task, release it. | Three separate witnesses: resource-side completion, graph result delivery or cancellation, and identity-checked worker/guardian termination. |
| `import_side_effect`, `artifact_changed` | Changed or undeclared code must not escape admission or directly update Bob. Import side effect attempts SQLite update; another case modifies the admitted artifact. | Independent Bob SQLite backup; artifact digest/activation record; no protected side effect. |
| `binding_principal`, `binding_invocation`, `activation_unconfirmed`, `cleanup_evidence_false`, `cleanup_unconfirmed` | Live checker must bind the caller/activation and withhold a result when cleanup is not confirmed. Mutate data at the actual production receiver. | Live checker record, worker `entered` event, resource-side state, result-release outcome, and cleanup process witness. These differ from offline certificate replay. |
| `preflight_principal`, `preflight_cedar`, `preflight_mac`, `preflight_admission`, `preflight_seatbelt`, `preflight_mediator`, `preflight_lean`, `preflight_audit`, `preflight_cleanup` | Remove one mandatory production component at a time. Preflight must refuse a supposedly complete configuration. | Named missing-component result before worker release and no resource `entered` event. Map `seatbelt` to Linux's required native isolation component. |
| `signal_controller`, `signal_guardian`, `direct_node`, `nested_entry` | These probe controller/guardian and declared trusted graph code. Compare only under an explicitly shared threat model; controller compromise is otherwise outside it. | Independent signal delivery or private-content observation and exact admission decision. |
| `suspended_worker`, `suspended_guardian`, `optional_permission` | Process suspension is a controlled scheduling test, not host sleep/wake. Optional `want` omission must be distinguished from lowerer tightening. | Worker/guardian identity and result after `SIGSTOP`/`SIGCONT`; Cedar grant and lowerer record for optional permission. |

`mach_inventory` and `debug_controller` are macOS-specific diagnostics. A Linux `/proc` or ptrace probe may be useful, but it would not be the same case without a separately agreed capability and oracle. The original debugger denial occurred in both conditions, so it cannot support an Argus-specific claim.
